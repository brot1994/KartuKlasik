# Kartu Klasik

FreeCell & Klondike bergaya Windows klasik untuk Android — meja hijau, menu abu-abu, animasi kartu memantul saat menang — plus **Permen Manis**, game cocok-3 permen warna-warni (mode Level 60 level + mode Santai, permen spesial, suara bisa dimatikan).

- Layout mengikuti HP: portrait, landscape, dan layar lipat terbuka
- FreeCell: nomor game 1–1.000.000 sama dengan FreeCell Windows, supermove, auto-naik kartu aman
- Klondike: ambil 1/3, skor Standar/Vegas/tanpa skor, selesai otomatis
- Undo tanpa batas, Hint, statistik, 4 pilihan punggung kartu, progres tersimpan otomatis

## Download
APK terbaru: tab **Releases → latest** (`KartuKlasik.apk`, atau versi `.zip`).

Dibuild otomatis oleh GitHub Actions setiap push ke `main`.
